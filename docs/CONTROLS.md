# Controls

Quick reference for Ascension: The Lost Archives.

## Movement

| Action               | Control                                     |
| -------------------- | ------------------------------------------- |
| Move                 | Click on ground/floor                       |
| Move to monster      | Click on monster (also enables auto-attack) |
| Move to interactable | Click on well, portal, tower entrance       |

## Combat

| Action             | Control                              |
| ------------------ | ------------------------------------ |
| Toggle auto-attack | Press `1` or click monster           |
| Use health potion  | Press `5`                            |
| Use skill          | Press `2,3,4,6-0` (must be unlocked) |
| Attack direction   | Character faces movement direction   |

**Auto-attack behavior:**

- ON (green border on skill): Automatically attacks enemies in front 180° cone within 3.5 units
- OFF (red label on skill): No automatic attacks
- Clicking floor disables auto-attack
- Clicking monster enables auto-attack

## UI

| Action                    | Control                  |
| ------------------------- | ------------------------ |
| Character screen          | Press `C`                |
| Inventory screen          | Press `I`                |
| View skills/attributes    | Character screen (C)     |
| Allocate attribute points | Character screen buttons |
| Equip/unequip items       | Inventory screen (I)     |

## Interactables

| Object         | Action                                  |
| -------------- | --------------------------------------- |
| Healing Well   | Click to approach and heal to full HP   |
| Tower Entrance | Click to enter tower (requires 5 kills) |
| Exit Portal    | Click to return to town from dungeon    |

## Progression

| Action              | Result                                               |
| ------------------- | ---------------------------------------------------- |
| Kill monsters       | Gain XP, level up at threshold                       |
| Level up            | +3 attribute points, unlock skills at levels 2, 4, 6 |
| Allocate attributes | Increase damage, health, regen                       |

## Skill Unlocks (All Classes)

| Level | Skills Unlocked                                       |
| ----- | ----------------------------------------------------- |
| 1     | Basic Attack, Health Potion                           |
| 2     | Primary skill (Power Strike / Aimed Shot / Fireball)  |
| 4     | Secondary skill (Whirlwind / Multi Shot / Frost Nova) |
| 6     | Utility skill (Battle Cry / Evasion / Heal)           |

## Skillbar Layout

| Slot | Key | Content                                       |
| ---- | --- | --------------------------------------------- |
| 1    | 1   | Basic Attack (toggle auto-attack)             |
| 2    | 2   | Primary skill (unlocked at level 2)           |
| 3    | 3   | Secondary skill (unlocked at level 4)         |
| 4    | 4   | Utility skill (unlocked at level 6)           |
| 5    | 5   | Health Potion (always available, shows count) |
| 6-10 | 6-0 | Locked (future skills)                        |

## Attributes

| Attribute | Effect                          |
| --------- | ------------------------------- |
| Strength  | +2 melee damage (Warrior)       |
| Agility   | +2 ranged damage (Archer)       |
| Intellect | +2 spell damage (Mage)          |
| Stamina   | +10 max HP, +1 HP regen per 30s |
